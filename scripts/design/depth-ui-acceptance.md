Release acceptance contract
1. Reading is primary: title, source/author, playable/illustrated material, meaningful narrative, relevant event/episode facts, clear original URL and observation age.
2. Machine metadata is not the body: feeds, digest references, item attributes and parser details belong in provenance disclosures/machine representations.
3. Real actions and no dead destinations: Open, Watch or Listen at source; Save and Share; installed app continuations only when bound and authorized. Account context not mixed with public reading.
4. Related content must be source/subject-joined, distinct, attributed and genuinely related, without duplicates or invented creator approval.
5. Navigation has territories (Work / Life / Live / Shop), public media modes, and separately account tools (Inbox / Saved / My apps / Create). A broken destination must be fixed or withheld.
6. Mixed media must differ by material: editorial reading, full-bleed photograph, movie poster, audio player, timed event, product/card and immersive room. No single generic inspector for all.
7. WebGL room is optional. Accessible list/card equivalent, keyboard navigation, focus visibility, reduced motion, no unauthorized media or application effects.
8. Show 390px and 1440px, signed-out and signed-in tests, actual clicking, 4-apex release readbacks and preservation/rights boundaries.
9. Never claim a source, CMS change or design screenshot is live without production acceptance.

Prototype in scripts/design/room-study.html
- A self-contained dark, responsive, no-build study with three physically shaded Three.js geometries (Gallery, Listening Room, Creator Studio) using pinned three@0.160.1 from CDN.
- The scene intentionally invents furniture/art; no external images, source copies, payments, account activity or publisher authorship.
- Preview with an ordinary static HTTP server after disk and runtime capacity permit. The HTML itself contains readable controls and content if WebGL fails. This is not hyperrealistic production rendering or a Google Stitch export.
