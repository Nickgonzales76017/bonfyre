# Public records and case systems

For public agencies and nonprofits replacing an old data portal, a forms system, a case management tool or a rules engine.

## What moves

Datasets, forms and their submissions, cases and their histories, the rules that decide eligibility or fees, and the public pages and downloads people already rely on.

## What we check first

- The datasets, forms and rules in the current system are listed, with personal data marked.
- Each rule carries the date it took effect, so older cases still work out the way they did at the time.
- What the public can read today stays readable after the move.

## How the result is checked

The new system runs next to the old one on the same cases for an agreed period. Every case where the two disagree is listed and explained before the old system is retired. Audit history moves with the records it describes.
