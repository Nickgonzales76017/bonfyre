# Documents and archives

For organizations moving a document library, a shared drive, a records archive or an old content management system into a new home.

## What moves

Files and their folders, the metadata attached to them, version history where it exists, access rights, and the retention rules that say when something may be deleted.

## What we check first

- The source system and the file formats in it are named.
- An approximate volume is known, so the first copy can be planned.
- Retention and access rules are written down before files move.

## How the result is checked

Every file is counted and fingerprinted before and after the move. Missing files, changed files and files whose access widened are listed. Formats that the new system cannot open are named with the options for each.
