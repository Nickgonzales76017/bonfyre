# Custom legacy applications

For businesses running an application built years ago by someone who has since moved on: an Access database, a classic ASP or early PHP site, a desktop program on a shared drive.

## What moves

It depends on the application. Usually the data, the screens people use every day, the reports, and the rules buried in the code that nobody wrote down.

## What we check first

- The language, framework and hosting the application runs on today.
- Whether the source code is available, and who may grant access to it.
- What the application does each day, in the words of the people who use it.

## How the result is checked

The old and new application are given the same inputs and their outputs compared. Behaviour that differs is listed and either fixed or accepted by you in writing.
