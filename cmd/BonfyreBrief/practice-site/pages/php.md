# PHP and WordPress sites

For the owner of a site stuck on an old PHP version, or a WordPress install whose plugins and theme nobody has touched in years.

## What moves

The site's code, its plugins and theme, its database, and its uploads, onto a supported PHP version and, if you want, a new host.

## What we check first

- The current PHP version and the version you are moving to are both named.
- Plugins, themes and custom code are listed, and the ones nobody maintains are marked.
- The site runs on a throwaway copy at the new version before the live site changes.

## What you can expect

A list of the code that breaks on the new version and why, the fixes made on the copy, and a copy you can click through yourself before anything goes live. Plugins with no maintained replacement are named, with the choices you have.
