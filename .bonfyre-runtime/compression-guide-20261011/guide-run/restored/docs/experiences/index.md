## One operation, several interfaces

A customer uses the finished application. An agency manages separate customer identities. A developer calls the native library or command. An assistant calls a scoped tool over MCP. The records, work, authority and economics remain with their native owners.

| Surface | What it provides |
|---|---|
| Website | Storefront, searchable content, intake, bookings and publishing |
| Partner workspace | Client configuration, roles, deployment and operational visibility |
| CLI and native API | Composition, inspection and programmatic execution |
| MCP and browser tools | Scoped operations through compatible assistants |
| Documentation | Tutorials, runnable examples, reference contracts and results |

## Work through an example

The [recording workspace guide](/recording-to-workspace) starts with a complete six-minute Webb telescope video. Search for an explanation, play its timestamp and save a note beside the transcript. The video, transcript and search index stay together in the local workspace.

A request or booking takes another route: an operator accepts the request, creates a commitment, and records the applicable invoice. Recorded payment is a separate step. The [request-to-books guide](/request-to-books) shows which record owns each transition.

## Build once; keep the customer distinct

White-label delivery includes the client's own host, visual design, content and tools. A client credential must not work against another client's data. Agency-wide configuration does not turn every customer into one shared identity.

The [white-label guide](/white-label-delivery) includes independent-brand examples and cross-customer refusal checks.

## Technical reference

Reference pages come from the bound operator contract and the selected Fabric execution state. They include inputs, outputs, invocation, limits, checks and recorded receipts. A command without a witnessed run still has usable reference documentation; it does not inherit another command's result.

Read the reference for the release you use. The navigation between applications, native libraries, integrations and assistant clients follows the same capability identities.
