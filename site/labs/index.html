01 / Applied probability

How many alerts are actually right?

A detector can have high sensitivity and still produce mostly false alerts when the event is rare. Try changing the event rate or the detector's false-positive rate.

Read the base-rate article ↗

With a 1% event rate, 95 true events and 495 ordinary cases are flagged. The detector catches most real events but most alerts are not real events.

The calculation uses expected counts (which may be fractional for some inputs) and assumes constant detection performance. It says nothing about the accuracy or fairness of a particular real system. Background: NIST face-recognition evaluations ↗.

02 / Inventory and resale

Is a discounted lot actually profitable?

Discounts compare asking prices with estimated retail value. Profit depends on what can actually be sold and what it costs to move the goods.

An advertised 80% discount does not produce an 80% margin. This hypothetical lot nets $650 before taxes, storage and the time value of your money.

Saleable inventory and recovery are estimates, not guarantees. Validate quantities, condition, seller terms, shipping and return policies before buying. See GSA Auctions ↗ for an example of real surplus listing conditions.
