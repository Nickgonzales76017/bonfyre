Start with a question

Use the machine at the right depth.

Bonfÿre can be approached as an architecture registry, a semantic conformance system, a native capability estate, a model commons, or an institutional product fabric. Pick one path and let receipts—not marketing copy—tell you what is live.

Practical paths

Each path is useful on its own. None requires pretending the entire Generation-10 destination is already implemented.

PATH 01

I want the architecture truth

Validate the Atlas, expand reversible views, inspect maturity and witnesses, and ask the loss report where coverage is thin.

bun architecture/atlas.mjs validate
PATH 02

I want executable semantic evidence

Run the frozen control-plane oracle for WorkGraph, capability, authority, evidence, Frappe, provider/resource, and replay behavior.

cd components/BonfyreControlPlane && python3 -m pytest tests/ -q
PATH 03

I want native capabilities

Build the command estate, synchronize subcommands, then inspect health. A named Power and a workload-proven realization are different facts.

make && ./cmd/BonfyreCLI/bonfyre list --health
PATH 04

I have an authorized observation

Turn an owned or authorized capture into typed artifacts, a recipe, and an inspectable composition plan.

bonfyre wire … → bonfyre stitch plan recipe.json
PATH 05

I need an institutional surface

Explore the nine Frappe grammars for relationships, work capacity, incidents, learning, accounting, evidence, knowledge, files, and derived views.

python3 components/BonfyreControlPlane/witness_frappe_apps.py
PATH 06

I need local model execution

Inspect Model Commons before choosing FPQ/FPQx, GGUF, local inference, context/cache, embedding, vector, SAE, speech, or an agent carrier.

bun architecture/atlas.mjs expand ModelView

What stays distinct

The whole machine becomes useful by connecting these organs without flattening their laws.

WorkGraphPurpose, dependencies, leases, cooling, and completion.
EffectKernelAuthority, idempotency, and effect ceilings at the boundary.
EvidenceGraphClaims, contradictions, receipts, witnesses, and divergence.
Model CommonsSpecialized model, context, retrieval, execution, and evaluation contracts.
Frappe ×9Institutional product grammars projected over shared semantics.
Partner CommonsExternal specialties that never inherit Bonfÿre ownership by connection.
Operational metabolismProvider readiness, resource weather, schedules, tools, and worker dependencies.
Financial metabolismAgreements, funding, payment state, allocation, and accounting.
AurekaiEvidence-bound learning, validation, promotion, cooling, and thaw.

From request to learning

request → identity / authority → CapabilityClosure → WorkGraph → provider + context + resource + funding admission → native | local model | bounded agent | external | human realization → EffectKernel → receipt / witness → replay / shadow / backtest → Aurekai candidate → proof gate → promote | cool | thaw
Human and authority line: reachability, a generated recipe, an agent suggestion, or a rendered control does not authorize an external effect. Inspect the plan and let Authority and EffectKernel decide at execution time.
