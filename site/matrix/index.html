From a project to an organization

A project can become an organization.

People often start with one project or shared interest. As participation grows, a group can add the tools, roles and processes needed to run it over time.

  1. 01Personal activity

    A project, shared interest, problem or idea.

  2. 02Shared participation

    People begin sharing work, records and decisions.

  3. 03Market or practice

    Regular activity may need payments, schedules and shared rules.

  4. 04Institution

    A company, co-op, crew, standard, community, or network.
