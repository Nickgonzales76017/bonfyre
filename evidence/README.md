# Evidence

This tree holds source-backed observations, receipts, recovery captures,
historical origins, and verification artifacts. It is not a second source tree.

- `origins/notebook-era/` preserves the absorbed Obsidian-era vault and its
  migration map with git history. Its `runtime/nightly-brainstorm/` child is a
  frozen writer implementation and run record, not an executable service.
- `recovery/` preserves bounded recovery captures and their provenance.
- `verification/` holds executable or inspectable verification artifacts.
- `fixtures/` holds stable conformance inputs, never mutable runtime output.

Historical material may inform EvidenceGraph or Aurekai learning. Its location
does not make historical claims current, proven, or authoritative.
