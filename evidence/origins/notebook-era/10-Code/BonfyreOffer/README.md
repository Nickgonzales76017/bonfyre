# Bonfyre Offer

Tiny native offer utility for turning proof bundles into lightweight market packages.

## What It Does

- `generate` an offer package from a proof bundle

## Build

```bash
cd 10-Code/BonfyreOffer
make
```

## Usage

```bash
arch -arm64 ./bonfyre-offer generate ../BonfyreProof/outputs/founder-sample-pickfu/proof-bundle.json ./outputs/founder-sample-pickfu
```
