===== BONFYRE HELP =====
bonfyre -- adaptive artifact pipeline toolkit

Usage: bonfyre <command> [args...]

Built-ins:
  list [term] [--json] [--compact]  Show command surface, filtered search, JSON, or compact mode
  completion [shell]    Emit shell completion for zsh, bash, or fish
  version       Print version
  help          Show this help

Start here:
  bonfyre doctor                 verify the installed surface
  bonfyre list model            filter command surface by topic
  bonfyre list --compact        compact one-line surface for fast scanning
  bonfyre list --json           inspect the command surface programmatically
  bonfyre completion zsh        generate shell completion
  bonfyre workflow list         inspect workflow profiles
  bonfyre family list           inspect conceptual family taxonomy
  bonfyre model list            inspect local model registry
  bonfyre recipe list           inspect recipe registry
  bonfyre run history           inspect indexed execution history
  bonfyre layer registry        inspect registered layer artifacts

System surfaces:
  Pipeline:  ingest -> mediaprep -> transcribe -> clean -> paragraph
             -> brief -> proof -> offer -> narrate -> pack -> distribute
  Workflows: workflow list / workflow show A3
  Families:  family list / family show T_CASEOPS / family where T_SHARED_QK
  Recipes:   recipe list / recipe show <name> / run <recipe-name> / run history / run show <id>
  Capabilities: capabilities help / capabilities match <description>
  Models:    model list / model family <family> / model route <stats.json>
  AI:        embed . vec . segment . sli . quant . fpq . fpqx . layer
  Infra:     hash . index . compress . graph . queue . sync . tel
  Value:     gate . meter . ledger . economy . compete

Run 'bonfyre list' for the full command surface, including discovered local extras.

                              entropy gate pass rate, auto-tune recommendations

### bonfyre transcribe
bonfyre-transcribe — world-class libwhisper transcription engine

Usage:
  bonfyre-transcribe <input-audio> <output-dir> [--model NAME] [--language CODE|auto]
                      [--media-prep-binary PATH]
                      [--silero-vad] [--silero-script PATH]
                      [--split-speech] [--noise-threshold DB] [--min-silence SEC]
                      [--min-speech SEC] [--padding SEC]
                      [--greedy] [--beam-size N] [--best-of N]
                      [--vocab-db PATH] [--no-vocab]
                      [--processors N] [--no-speech-thold N]

Transcription engine:
  Links libwhisper directly. Model loads ONCE. Zero fork+exec.
  Metal GPU + flash attention. DTW forced-alignment timestamps.
  Multi-processor parallel decode. TinyDiarize speaker turns.

Quality (cutting-edge):
  Geometric mean confidence (perplexity^-1 = exp(mean(log(p)))).
  Compression ratio hallucination detection (zlib, rho > 2.4).
  Token n-gram repetition detector. Repetition penalty logits filter.
  Voice-length anomaly detection. Per-segment quality score.

Output formats:
  transcript.txt   — plain text
  transcript.json  — structured segments with timestamps, confidence,
                     logprob, compression ratio, hallucination flags
  transcript.srt   — SubRip subtitles
  transcript.vtt   — WebVTT subtitles with quality metadata

Vocabulary learning:
  Flat binary .bfvocab format (BFVD02). Zero SQLite, zero process spawns.
  BM25-weighted terms injected as whisper initial_prompt.
  Token-aware truncation to fit decoder context (112 token budget).
  Shannon entropy + KL-divergence track convergence.

  BM25(t,d) = IDF(t) * tf(t,d)*(k1+1) / (tf(t,d)+k1*(1-b+b*|d|/avgdl))
  H = -sum(p_i * log2(p_i))           [Shannon entropy]
  D_KL(P||U) = sum(p_i * log2(p_i/q)) [KL from uniform]

  Disable with --no-vocab. Custom path with --vocab-db.
