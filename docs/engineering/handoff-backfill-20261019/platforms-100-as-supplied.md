## Access Tier Breakdown Key

1. **Tier 1 — Open / Permissive Access:** No approval process needed; instant API keys, webhooks, or open protocols (e.g., RSS, ActivityPub, AT Protocol).
2. **Tier 2 — Self-Service / Standard Developer Portal:** Requires creating a developer account, agreeing to TOS, and generating credentials instantly or with basic OAuth setup.
3. **Tier 3 — App Verification / Basic Audit:** Standard developer signup plus automated/light compliance checks, identity verification, or basic app consent review.
4. **Tier 4 — Strict Enterprise & Manual App Review:** In-depth human review, business verification, strict data privacy audits, partner tier requirements, or vetted apps through their internal developer teams.
5. **Tier 5 — Private / Closed / Gated API:** Fully restricted ecosystem. No public API available; integrations require custom enterprise partnerships, white-label deals, or custom scraper/ingestion pipelines.
