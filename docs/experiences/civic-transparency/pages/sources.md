# Where this comes from

Every number and record on this site comes from a public source we can name, read on a day we can name. This page lists them, says how far to trust each kind, and records every read we tried, including the ones that failed.

## How far to trust each kind of source

Each line on the site says which of these it comes from. Higher on the list counts for more.

1. A city's own record: a contract, a vote, a written policy. This is what the city committed to on paper.
2. Records a city released to someone under the Public Information Act. These are the city's documents, though redactions can leave gaps.
3. The volunteer map on OpenStreetMap. People tag a reader after seeing it. Cities have not confirmed these, and the map can be behind or ahead of what is on the street.
4. News reporting, linked to the story, for context only.

We do not use guesses, posts about a single sighting, or anything that tracks a particular person or car.

## The sources

| Source | What we take | Terms |
|---|---|---|
| OpenStreetMap | Counts of mapped license plate readers by town and county | Open Database License; attribution to OpenStreetMap contributors |
| City council agenda records (Legistar) | Agenda items that name plate readers or Flock: title, date, status and the city's link | Public records published by each city |

The town counts are asked of a public Overpass server, which returns only the totals. We picked a server whose robots rules allow it. The main Overpass server asks automated readers to stay out of its query address, so we leave it alone.

## Every read

Each read is kept with a fingerprint of exactly what came back. A page here is rebuilt only from reads that still match their fingerprint.
