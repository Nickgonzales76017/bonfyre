# Fix something

If something here is wrong, tell us and it gets checked against a public record before anything changes. Every correction is posted on the front page with its date, so readers can see what changed.

## A camera count looks wrong

The counts come straight from OpenStreetMap, so the fix belongs there. Anyone can edit the map; the [tagging guide for plate readers](https://wiki.openstreetmap.org/wiki/Tag:surveillance:type%3DALPR) explains how readers are tagged. The next time this site reads the map, the count follows.

## A council record is missing or wrong

Send the item number or the link to the city's page through the [contact page](/contact). We read it on the city's own site. If it names plate readers or the camera company, it goes on the council page with the day we read it.

## Something here could point to a person

Tell us through the [contact page](/contact). We take it down first and check afterwards.

## What we will not take

- License plate numbers, or reports of where a particular car was seen.
- Names, addresses or photos of private people.
- The exact spot of a single camera. The map already holds those, and this site counts by town.
- Anything sent with a request to keep the sender's name on the site. We publish no sender names.

## How a correction moves

1. It arrives through the contact page.
2. We find the public record that supports it: the city's page, a released document or the map itself.
3. If the record supports it, the page is rebuilt from a fresh read and a dated note goes on the front page.
4. If no public record supports it, nothing changes and we say why in the reply.
